# 内存管理

内存管理的主要任务是为多道程序的运行提供良好的环境，包括内存的分配与回收、地址转换、内存保护和内存扩充。

## 逻辑地址与物理地址

程序中使用的地址称为**逻辑地址**，内存单元的实际地址称为**物理地址**。将逻辑地址转换为物理地址的过程称为**地址重定位**。

## 分页存储管理

分页把进程的逻辑地址空间划分为大小相等的**页**，把物理内存划分为同样大小的**页框**。系统为每个进程建立一张**页表**，记录页号到页框号的映射。

逻辑地址 = 页号 × 页大小 + 页内偏移。

为了加快地址转换，硬件提供了快表（TLB），它是一种高速缓存，存放最近访问过的页表项。

## 虚拟内存

虚拟内存基于**局部性原理**：程序在一段时间内只访问一小部分代码和数据。局部性包括：

- 时间局部性：最近访问过的数据很可能再次被访问；
- 空间局部性：与当前访问地址相邻的数据很可能即将被访问。

当访问的页面不在内存中时会产生**缺页中断**，操作系统从外存调入该页。若内存已满，需要通过页面置换算法选择一页换出：

| 算法 | 说明 | 特点 |
| --- | --- | --- |
| OPT | 淘汰以后最长时间不再使用的页 | 理论最优，无法实现 |
| FIFO | 淘汰最早进入内存的页 | 可能出现 Belady 异常 |
| LRU | 淘汰最近最久未使用的页 | 性能接近 OPT，开销较大 |
| CLOCK | 用访问位近似 LRU | 实现简单，开销小 |

> 如果分配给进程的页框太少，进程会频繁缺页，大部分时间用于页面换入换出，这种现象称为**抖动**。
