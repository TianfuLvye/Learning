# 进程管理

进程（Process）是操作系统进行**资源分配**和调度的基本单位。程序是静态的指令集合，而进程是程序的一次执行过程，是动态的。

## 进程的组成

一个进程通常由三部分组成：

- **程序段**：进程要执行的代码；
- **数据段**：进程运行过程中处理的数据；
- **进程控制块（PCB）**：操作系统感知进程存在的唯一标志。

PCB 中保存了进程标识符、处理机状态、进程调度信息和进程控制信息。操作系统通过 PCB 来管理和控制进程，进程创建时创建 PCB，进程撤销时回收 PCB。

## 进程的状态

进程在生命周期中会在以下三种基本状态之间转换：

| 状态 | 含义 |
| --- | --- |
| 就绪态 | 进程已获得除 CPU 以外的所有资源，等待 CPU |
| 运行态 | 进程正在 CPU 上执行 |
| 阻塞态 | 进程等待某一事件（如 I/O 完成）而暂停运行 |

![进程状态转换图](images/process-states.svg)

状态转换规则：

1. 就绪态 → 运行态：进程被调度程序选中，获得 CPU。
2. 运行态 → 就绪态：时间片用完，或被更高优先级的进程抢占。
3. 运行态 → 阻塞态：进程请求某一资源或等待某一事件。
4. 阻塞态 → 就绪态：等待的事件已经发生。

> 注意：阻塞态不能直接转换为运行态，必须先进入就绪态，再由调度程序选中。

## 进程与线程

线程是 CPU 调度的基本单位，进程是资源分配的基本单位。同一进程内的多个线程共享进程的地址空间和资源，但每个线程拥有独立的栈和寄存器上下文。

引入线程的好处：

- 线程切换开销小于进程切换；
- 同一进程内线程间通信更简单；
- 提高了系统的并发性。

## 进程调度算法

常见的调度算法包括：

- **先来先服务（FCFS）**：按到达顺序调度，对长作业有利，对短作业不利。
- **短作业优先（SJF）**：平均等待时间最短，但可能导致长作业“饥饿”。
- **时间片轮转（RR）**：每个进程轮流执行一个时间片，适用于分时系统。
- **优先级调度**：优先级高的进程先执行，可分为抢占式和非抢占式。

```c
// 用 fork() 创建子进程
pid_t pid = fork();
if (pid == 0) {
    printf("子进程\n");
} else {
    printf("父进程，子进程 PID = %d\n", pid);
}
```
